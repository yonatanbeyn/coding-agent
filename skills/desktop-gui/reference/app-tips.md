# App-specific tips

## Postman
- New request tab: `cmd+t`
- Send request: `cmd+enter`
- The URL bar is at the top of the request tab ("Enter URL or paste text").
- The method dropdown (GET/POST…) sits directly left of the URL bar.

## Chrome
- New tab: `cmd+t` · Address bar: `cmd+l` · Reload: `cmd+r`

## IntelliJ IDEA
- Search everywhere: press `shift` twice · Run: `ctrl+r` · Terminal: `opt+f12`

## Slack
- Jump to conversation: `cmd+k` · Send message: `enter`
